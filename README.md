# Scholarship & Aid Distribution Verifier System

This repository contains a full-stack DBMS project for scholarship application verification and aid disbursement tracking.

The main project files are inside:

```text
scholarship-aid-distribution-verifier-system/
```

Open the full project README here:

[Scholarship & Aid Distribution Verifier System README](scholarship-aid-distribution-verifier-system/README.md)

## Quick Overview

The application has two main portals:

- Student Portal: students enter `Student_ID` to view scholarship status, disbursed amount, and payment mode.
- Verifier Dashboard: authorities log in with `Authority_ID` and password, approve/reject pending applications, and undo processed decisions.

## Tech Stack

- React + Vite + Tailwind CSS
- Node.js + Express.js
- Oracle Database
- `oracledb` npm package
